## 1. 読み方

計算書側の「キー」はセル参照(`ref`)です。専用のキー名は無く、表の1行がまるごと1セルの
文字列(空白パディングで桁揃え)に入っているため、値は文字列から切り出します。

```python
import json
d = json.load(open('docs/references/アライズ鋼管矢板岸壁.json', encoding='utf-8'))
ref = {c['ref']: c['text'] for s in d['sheets'] for r in s['rows'] for c in r['cells']}
ref['A106']   # '1     1100.0       22.0    (L-T)型[L-75x75x9]'
```

`ref` はシート跨ぎで一意ではありません。同名セルが両シートに存在する場合は
`d['sheets'][0]` / `[1]` を明示してください。本表では **S0** = `Page 1～50`、
**S1** = `Page 51～93` と表記します。

結果サマリ表・トライアル結果表のみ複数セルに分かれており、列が状態に対応します。

| 列 | 状態 |
|---|---|
| `Q` | 永続状態 |
| `AM` | 変動状態(L1地震動) |
| `BI` | 変動状態(けん引力) |

信頼度ラベル(CLAUDE.PRIVATE.md §3):**確定** = 計算書に直接記載 /
**概算** = 単純な四則演算で導出 / **推定** = 定義の解釈を伴う。

## 6. 注意点

### 6-1. `span_length` / `SpanM` の定義差(最重要)

計算書の「前面矢板-控え工間距離 19.500 m」は前面矢板と控え工の **中心間距離**と解釈
されます(S1 `A1171`〜`A1173` の崩壊角・lm1/3 による決定方法から)。一方 009 の
`span` は `AnchorAlignment.cs:77` の `anchorAxisX = frontAxisX + SpanM - OuterDm / 2.0`
より **前壁矢板中心 〜 控え杭の陸側定着面**です。

したがって中心間距離として使う場合は控え杭の半径分を加算します。

```
SpanM = 19.500 + 1.000 / 2 = 20.000 m
```

**計算書に間距離の定義図(EMF)が含まれているため、採用前に原本 xlsx で図を確認して
ください。**中心間距離という解釈が誤りであれば 0.5 m の系統誤差が入ります。
なお `CrossMemberValidator` はタイロッドと控え杭の span 一致を要求するため、
両者に同じ値を与える必要があります。

### 6-2-1. 土質定数 → 柱状図 CSV(`docs/samples/boringlog_arise.csv`)

009 は土質定数そのものを使いませんが(§6-3)、**打設歩掛積算が要求する加重平均N値**の
入力として、S0 `A189`〜`A197`【土質定数(陸側)】から柱状図 CSV を起こしています。

| NO | 標高上端 (m) | 標高下端 (m) | 計算書の定数 | 土質区分 | N 値 | 信頼度 |
|---|---|---|---|---|---|---|
| 1 | 3.00 | −8.10 | φ=40.0、γ=18.0 / γt=20.0 | 砂質土等 | 31 | 推定 |
| 2 | −8.10 | −11.00 | φ=38.0、γ=18.0 / γt=20.0 | 砂質土等 | 26 | 推定 |
| 3 | −11.00 | −17.50 | φ=38.0、γ=18.0 / γt=20.0 | 砂質土等 | 26 | 推定 |

- **層境界の標高は確定**(表の `標高` 列は各層の上端。土圧計算表 S0 `A566`〜`A591` の
  層区分と一致することを確認済み)。土圧計算表側は水位面 +1.00 m・海底面 −12.60 m 等で
  さらに細分されるが、土質定数が変わらないため柱状図では分割しない
- **N 値は計算書に無い**ため換算した。砂質土:大崎式 `N = (φ−15)² / 20`、
  粘性土:`c = 6.25N`(テルツァギ・ペック)より `N = c / 6.25`
- 最下層の下端は計算書では −50.00 m(土圧計算範囲)だが、柱状図としては前壁の
  杭先端 −29.00 m の 6 m 下 = **−35.00 m を調査終了深度**とした
- 実案件では**実測の柱状図に差し替えること**。上表は形式と桁を確認するためのサンプル

### 6-3. 対応しない項目

計算書側にあって 009 に無いもの:土質定数(S0 `A189`〜。§6-2-1 のとおり柱状図 CSV
サンプルの N 値推定にのみ使用)、部分係数(S0 `A228`〜)、
土圧・崩壊角、照査結果 m･Sd/Rd、断面性能、腐食しろ、震度。009 は形状生成と施工歩掛
積算が目的で断面計算を行わないため、これらは入力ではなく**外部で決まった結果**として
扱います。

009 側にあって計算書に無いもの:`piece_index` / `piece_count`(施工順位・本数)、
`tie_count`、定着金物寸法、`color`、`PositionY`、`ClosedTip`。施工・モデル固有の
情報のため、積算基準や現場条件から別途与えます。

### 6-4. 整合性の検証結果

この計算書の値を 009 に入力した場合、以下が成立します。

| 検証項目 | 結果 |
|---|---|
| 有効幅:009 `JointGeometry.EffectiveWidth(1.1, LT75)` = 1.178086 m ⇔ 計算書 `A295` 1.17809 m | 一致(差 0.004 mm) |
| `tie_spacing` が `pile_pitch` の整数倍(`TieRodParameters.Validate` 項目7) | 2.356 / 1.178086 = 2.000(ずれ 0.17 mm < 許容 1 mm)→ **合格** |
| `waling_height` ≦ `pile_d`(同 項目4) | 0.380 ≦ 1.100 → 合格 |
| `pile_pitch` ≧ `pile_d`(同 項目5) | 1.178 ≧ 1.100 → 合格 |
| 控え杭:`TipElevM` + `LengthM` = 天端標高 | −10.500 + 12.500 = +2.000 → S1 `A1161` と一致 |
| 前壁:`head_z` − 全長 = 杭先端標高 | 1.500 − 30.500 = −29.000 → S0 `Q274` と一致 |

有効幅の一致は、009 の LT75 継手式(`JointGeometry.JointSpacing`)が実務ソフトと同じ
結果を返すことの実証です。

`rod_d` は計算書から決まりません。`F270T` の呼び径をメーカーカタログで確認するまで
タイロッドのモデル生成はできません(009 の `TieRodCatalog` は φ25〜φ90 の規格径のみ
受け付けます)。
